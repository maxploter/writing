# CLAUDE.md

Instructions for agents working in this repo.

## What this repo is

This repo holds my finished writing and the site that publishes it (Jekyll, built by GitHub
Pages from `main`). Sections are subjects, not forms: `literature/`, `philosophy/`,
`technology/`. Add a section only when a piece doesn't fit any of them.

Each piece is one Markdown file, `<section>/<slug>.md`, with this front matter:

    ---
    layout: page
    title: The title
    date: 2026-11-01
    ---

Commit messages start with the section name (for example `literature: ...`).

## This repo is public

Everything here, including git history, is public and stays public. Only finished pieces go in
here. Drafts stay out. Never commit anything about my private life or my employer unless I have
put it in a finished piece myself.

## The words are mine

Don't write or rewrite pieces. Edit by pointing out what's wrong, and leave the changes to me.

## Agent memory does not live here

This repo holds my writing and the site, nothing else. Agent memory lives in the KnowledgeNexus
workspace. This repo is not a submodule there.
